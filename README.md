# не тупи, поступи

Сервис для школьников и абитуриентов: помогает понять, кем стать, подобрать вуз или колледж в России и за границей и ведёт до зачисления — документы, экзамены, визы, деньги. Спокойно и по шагам.

## Что в репозитории

```
site/
  index.html    главная страница
  podbor.html   анкета подбора (≈20–30 вопросов, ветвление по ответам)
data/
  schema.json   схема записи об учебном заведении
  README.md     правила наполнения базы
  institutions/ записи о вузах и колледжах (ru/, abroad/)
  photos/       фото со свободной лицензией
scripts/
  validate.py   проверка базы по схеме
```

## Как посмотреть сайт

Открыть `site/index.html` в браузере. Сборка не нужна: чистый HTML, CSS и JS.
