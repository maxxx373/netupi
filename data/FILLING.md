# Как заполнять карточку учебного заведения

Инструкция для всех, кто дополняет базу: людей, Claude, Кодекса. Схема полей — `data/schema.json`, общие правила — `data/README.md`.

## Полная карточка

Карточка считается готовой, когда в ней есть всё ниже. Чего нет на официальных источниках — не выдумываем, а пишем короткий пункт в `todo`.

| Блок | Поля | Что внутри |
|---|---|---|
| Основа | `name` (ru, en, short, local), `city`, `city_size`, `ownership`, `founded`, `website`, `admissions_url`, `intl_students_url` | `name.ru` — по-русски, даже для зарубежных вузов |
| Описание | `summary`, `highlights`, `about` | `summary` 2–4 предложения своими словами |
| Обучение | `fields`, `levels`, `languages_of_instruction`, `study_formats`, `programs` | 3–6 популярных программ с ценой, проходным баллом и годом |
| Деньги | `cost`, `funding` | цена в местной валюте за год; гранты и стипендии, особенно для иностранцев |
| Требования | `requirements` | ЕГЭ/ОГЭ, ДВИ, олимпиады, IELTS/TOEFL/SAT и др., портфолио, документы. Для зарубежных: принимают ли российский аттестат напрямую или нужен foundation / год вуза |
| Сроки | `deadlines` | окна подачи для основного набора, с годом кампании |
| Жильё | `dorm` | есть ли, гарантия на 1 курс, цена в месяц |
| Виза | `visa` | только для зарубежных: нужна ли гражданам РФ, тип, особенности |
| Рейтинги | `rankings` | QS, THE, RAEX — с годом. Колледжам: пусто и пункт в `todo` не нужен |
| Плюсы | `perks` | из списка в схеме |
| Советы | `prep` | `must` и `good`, 1–3 предложения на русском, на «ты», только по фактам из карточки |
| Фото | `photos` | минимум одно, со свободной лицензией |
| Учёт | `sources`, `verified_at`, `data_year`, `confidence`, `todo` | каждая страница, с которой взят факт |

`confidence`: `high` — почти всё с официальных страниц текущего или прошлого года; `medium` — основное есть, часть пробелов; `low` — мало данных.

## Источники

1. Официальный сайт: страницы приёма, цен, общежитий, раздел для иностранцев, официальные PDF.
2. Официальные порталы государства: визы (посольства), признание дипломов, «Учёба в России», UCAS, uni-assist и т.п.
3. Рейтинги — с сайтов самих рейтингов (raex-rr.com, topuniversities.com, timeshighereducation.com) или из официальной новости вуза.
4. Агрегаторы — только если официального нет, и это помечается в `note` и `covers`.

Если сайт требует JavaScript, его можно открыть обычным браузером (Playwright + Chromium). Капчи не решаем и защиту не обходим: если доступ закрыт — берём другие официальные источники и пишем в `todo`.

## Фото

- Только свободные лицензии: Wikimedia Commons (CC BY, CC BY-SA, CC0, Public domain) и т.п. С официальных сайтов фото не берём.
- Скачивание: `https://commons.wikimedia.org/wiki/Special:FilePath/<Имя_файла>?width=1280` с User-Agent `netupi-data-bot/0.1`, между запросами пауза в несколько секунд (Wikimedia ограничивает частоту).
- Файл: `data/photos/<id>/1.jpg`, ширина ~1280 px, до 500 КБ. В карточке путь `photos/<id>/1.jpg`, автор, лицензия, ссылка на страницу файла.
- Проверка: `file data/photos/<id>/1.jpg` должен показать JPEG, а не HTML.
- Лучше главное здание или кампус. Нет фото вуза — подойдёт здание, где он находится, если это понятно из описания файла.
